Maintenance Mode

Blocks all bot commands clan-wide. Use during maintenance or incidents.

Comma-separated channel IDs where public text commands are silenced.

Below this member count, the Analytics overview flags the clan as under-strength ahead of matchmaking.

War Reset Hour (UTC)

Approximate daily war-day reset hour, used to time the tiered 50%/90% war reminders.

Auto-Strike Threshold

Consecutive war weeks with 0 decks used before an automatic strike + DM is issued. Set to 0 to disable (default).

Quiet Hours (UTC)

Automated DMs (war nudges, warnings) are held — not dropped — during this window, and retried after it ends.

Channels & Automated Posts
War Nudge Channel

Discord channel ID where the bot posts war nudge mentions.

Changelog Channel ID

Where auto-posted "settings/template changed" lines go. Falls back to the announcements channel, then the War Channel, only if Channel-ID Fallback below is enabled.

Announcements Channel ID

Dedicated channel for all automated posts (war recaps, milestones, digests, role changes) so they don't bury real conversation in the War Channel.

Leadership Escalation Channel ID

Where escalation alerts go when a member ignores every war-day nudge tier. Falls back to the announcements channel only if Channel-ID Fallback below is enabled.

Automated War-Deck Pings

Automatically DM members who still have war decks left as the day winds down.

Automated War Reminders

Post a reminder in the war channel when a River Race day begins.

Beta Test Group Role ID

Discord role ID used by the /syncbeta slash command — nickname sync is manual/on-demand only, never automatic.

Database Backup Channel ID

Where the daily full-database backup .zip gets posted (e.g. your "warbot logs" channel). If Channel-ID Fallback below is off, nothing posts unless this is filled in directly.

Channel-ID Fallback

When a specific channel above (Backup, Leadership, Announcements, Changelog) is left blank, the bot used to silently fall back to a different channel -- which could mean posts land somewhere unexpected. Off by default: if a channel isn't explicitly set, that post is skipped instead of redirected.
